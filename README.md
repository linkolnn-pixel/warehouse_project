📦 Warehouse Management System
Веб-система управления складом, товарами, продажами и складскими операциями, разработанная на Django.

Проект объединяет складской учёт и аналитический модуль: позволяет управлять каталогом товаров, приходами и продажами, контролировать остатки, отслеживать движения товаров и анализировать выручку и эффективность ассортимента.

🚀 Основные возможности
📦 Управление складом
Просмотр текущих остатков товаров

Расчёт общего количества товара на складе

Расчёт закупочной стоимости остатков

Расчёт розничной стоимости остатков

Расчёт потенциальной прибыли

Контроль товаров с нулевым или отрицательным остатком

История движений товаров

Группировка операций по документам

Система рассчитывает остаток товара на основе операций прихода (IN) и расхода (OUT).

📈 ABC-анализ
Отдельный аналитический модуль выполняет ABC-анализ ассортимента по выручке.

Товары сортируются по общей выручке от проведённых продаж, после чего распределяются по классам:

Класс	Доля накопленной выручки
🟢 A	до 80%
🟡 B	80–95%
🔴 C	95–100%

Для каждого товара отображаются:

название;

SKU;

выручка;

доля в общей выручке;

ABC-класс.

Таким образом, можно быстро определить товары, которые формируют основную часть оборота.

🗑️ Soft Delete
Для товаров и контрагентов используется механизм мягкого удаления.

Вместо физического удаления записи устанавливается:

is_deleted = True

Обычные запросы работают только с активными объектами, а полный набор записей остаётся доступен через all_objects.

Это позволяет сохранять исторические данные и не терять информацию о прошлых операциях.

⚙️ Установка
1. Клонирование репозитория
git clone https://github.com/linkolnn-pixel/warehouse_project.git
cd warehouse_project

2. Создание виртуального окружения
Windows
python -m venv .venv
.venv\Scripts\activate

Linux / macOS
python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt

📊 Логика расчёта склада
Остаток товара рассчитывается на основании складских операций:

Остаток = Приход − Расход

Например:

Приход: 100 шт.
Продажа: 25 шт.
Продажа: 10 шт.

Остаток = 100 − 25 − 10 = 65 шт.

Для товара также рассчитывается потенциальная прибыль:

Прибыль с единицы =
Цена продажи − Закупочная цена

и:

Потенциальная прибыль склада =
Остаток × Прибыль с единицы

Эта логика реализована непосредственно в модели Product.

🔐 Безопасность и целостность данных
В проекте предусмотрены механизмы защиты данных:

проверка количества товара перед продажей;

запрет редактирования уже проведённых документов;

возможность отмены проведения;

транзакции базы данных при операциях с документами;

PROTECT для критически связанных объектов;

soft delete для товаров и контрагентов;

уникальные внутренние коды товаров;

уникальные номера документов.

Операции создания и проведения документов выполняются с использованием transaction.atomic, что позволяет сохранить целостность связанных изменений.
