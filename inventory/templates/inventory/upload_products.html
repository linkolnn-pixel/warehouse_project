📋 Правила загрузки:
  • Бренд (Колонка "Бренд"): Обязательно! Это создаст категорию (например, Angiopharm). Без бренда товар не загрузится.
  • Артикул (SKU): Если есть — обязательно заполни. Это главный ключ для поиска дублей.
  • Объем / Вес: Заполни хотя бы одно поле. Если пусто — будет 0.

Пример структуры вашего Excel файла:

Колонка в Excel Что будет в базе Статус
Бренд Категория (создается автоматически) ОБЯЗАТЕЛЬНО
Артикул SKU (Ключ для проверки дублей) Рекомендуется
Наименование Name ОБЯЗАТЕЛЬНО
Объем Quantity Value (число) + Measure Unit = 'мл' Опционально
Вес Quantity Value (число) + Measure Unit = 'г' Опционально (если нет объема)
Ед. изм. Unit (шт, упак, набор) По умолчанию 'шт'
Закупочная цена Cost Price (Decimal) ОБЯЗАТЕЛЬНО
Цена продажи Sale Price (Decimal) ОБЯЗАТЕЛЬНО

💡 Важно: В Excel используйте точку или запятую для дробных чисел (скрипт сам исправит запятые на точки). Названия брендов должны совпадать точно (Angiopharm ≠ angiopharm), либо скрипт создаст новый бренд.
